### TEST 06 路线策略 (RoutePreference)
- **结论**：**PASS**
- **证据**：
  - 审查发现旧原型写死 `policy: 7`（实为躲避收费且躲避拥堵，但并未排斥免费高速）；
  - 重构创建 `src/types/preference.ts`，将用户偏好抽象为：
    - `avoidHighway: true`（不走高速）
    - `avoidToll: true`（尽量避免收费）
    - `avoidCongestion: false`（自驾风景优先，避免绕行未知小道）
  - 依据高德 JS API 2.0 官方规范，将上述组合精确映射为 `policy: 5`（不走高速且避免收费）与 `policy: 8`（全避让）；
  - `CenterMapArea` 与 `amapService.planSegment` 全部由统一偏好驱动。
- **问题**：旧代码 policy 语义不符合“不走高速”的核心诉求。
- **修复**：实现 `mapPreferenceToAMapPolicy` 抽象函数并在全服务层接入。

### TEST 11 加入停靠点 (Waypoint 真实重算路与 Undo)
- **结论**：**PASS**
